# PHẦN MỀM GIẢI PHƯƠNG TRÌNH BẬC NHẤT
## 1. Giới thiệu
Phần mềm giải phương trình bậc nhất một ẩn có dạng:
ax + b = 0
Chương trình được viết bằng Python, có giao diện
người dùng được thiết kế bằng Qt Designer.
## 2. Chức năng
- Nhập hai hệ số a và b.
- Giải phương trình khi a khác 0.
- Thông báo phương trình vô nghiệm.
- Thông báo phương trình có vô số nghiệm.
- Kiểm tra dữ liệu nhập không hợp lệ.
- Xóa dữ liệu để nhập lại.
## 3. Công nghệ sử dụng
- Ngôn ngữ lập trình: Python
- Công cụ thiết kế giao diện: Qt Designer
- Thư viện kết nối giao diện Python
## 4. Cấu trúc dự án
- File giao diện được tạo bằng Qt Designer: định nghĩa các thành phần giao diện người dùng.
- File xử lý phương trình: chứa hàm giải phương trình bậc nhất.
- File chương trình chính: kết nối giao diện với chức năng giải phương trình.
- README.md: tài liệu giới thiệu dự án.
## 5. Cách chạy chương trình
Hướng dẫn chạy chương trình sẽ được cập nhật sau khi hoàn thiện và kiểm thử phần mềm.
## 6. Phân công thành viên
- Thành viên 1: Quản lý và tích hợp dự án.
- Thành viên 2: Xây dựng hàm giải phương trình.
- Thành viên 3: Thiết kế giao diện bằng Qt Designer.
- Thành viên 4: Kiểm thử chương trình.
- Thành viên 5: Quản lý GitHub và tài liệu.
## 7. Kiểm thử

sau khi hoàn thiện chương trình.
