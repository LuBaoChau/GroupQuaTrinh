#PHẦN MỀM GIẢI PHƯƠNG TRÌNH BẬC NHẤT

## 1. Giới thiệu
Phần mềm giải phương trình bậc nhất một ẩn
có dạng ax + b = 0.

Chương trình được viết bằng Python và sử dụng
thư viện Tkinter để tạo giao diện người dùng.

## 2. Chức năng
- Nhập hệ số a và b.
- Giải phương trình khi a khác 0.
- Thông báo phương trình vô nghiệm.
- Thông báo phương trình có vô số nghiệm.
- Kiểm tra dữ liệu nhập không hợp lệ.
- Xóa dữ liệu để nhập lại.

## 3. Công nghệ sử dụng
- Ngôn ngữ lập trình: Python
- Thư viện giao diện: Tkinter
- Môi trường lập trình: PyCharm

## 4. Cấu trúc dự án
- main.py: Chương trình giao diện chính.
- solver.py: Hàm xử lý và giải phương trình.
- README.md: Tài liệu giới thiệu dự án.

## 5. Cách chạy chương trình
1. Cài đặt Python.
2. Tải mã nguồn về máy.
3. Đặt main.py và solver.py trong cùng thư mục.
4. Mở Terminal tại thư mục dự án.
5. Chạy lệnh: python main.py

## 6. Phân công thành viên
- Thành viên 1: Quản lý và tích hợp dự án.
- Thành viên 2: Xây dựng hàm giải phương trình.
- Thành viên 3: Thiết kế giao diện.
- Thành viên 4: Kiểm thử chương trình.
- Thành viên 5: Quản lý GitHub và tài liệu.

## 7. Kiểm thử
Ghi lại các trường hợp kiểm thử và kết quả thực tế
của chương trình tại đây.
